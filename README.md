# SistemaInventario

Aplicación de gestión de inventarios para Windows desarrollada con C# y .NET 10.

## Tecnologías

- C#
- .NET 10
- WPF / XAML
- Entity Framework Core
- SQLite
- LINQ

## Funcionalidades

- Gestión de productos
- Gestión de clientes
- Registro de ventas
- Movimientos de inventario
- Entradas y salidas de productos
- Reportes
- Configuración
- Búsqueda y filtrado
- Base de datos local SQLite
- Interfaz gráfica para Windows

## Descripción

SistemaInventario es una aplicación de escritorio orientada a pequeños negocios y comercios que necesitan gestionar productos, existencias, clientes, ventas y movimientos de inventario.

El proyecto fue desarrollado utilizando C# y tecnologías modernas de .NET, aplicando programación orientada a objetos, acceso a datos con Entity Framework Core y almacenamiento local mediante SQLite.
